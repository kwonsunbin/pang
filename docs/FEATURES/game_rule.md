# 게임 룰 상세 (Game Rules)

## 기본 목표
맵 안에서 튕겨 다니는 **모든 방울(Bubble)을 와이어(Wire)로 쏴서 소멸**시키면 승리합니다.

---

## 게임 오브젝트

### 플레이어 (Player)
- 화면 **하단 중앙**에서 시작
- **← → 방향키**로 좌우 이동
- 화면 좌우 벽 밖으로 이동 불가
- 방울과 충돌 시 즉시 **목숨 1 감소**

### 와이어 (Wire)
- **Space 키** 입력 시 플레이어 위치에서 **수직 위 방향**으로 발사
- 천장 또는 벽에 닿을 때까지 위로 뻗어나감
- 방울에 적중하면 방울을 **파괴 또는 분할**시키고 소멸
- 동시에 1개의 와이어만 존재 가능 (이전 와이어가 사라져야 재발사 가능)

### 방울 (Bubble)
- 좌/우 방향으로 이동하며 **중력의 영향**을 받아 포물선 운동
- 바닥·벽·천장·블록에 닿으면 **반사(튕김)**
- 모든 방울은 동일한 최고 높이까지 튀어 오름

#### 방울 크기 및 분할 규칙
| 크기 | 와이어 적중 결과 |
|---|---|
| Large (대) | Medium(중) 2개로 분할 — 좌/우로 분산 |
| Medium (중) | Small(소) 2개로 분할 — 좌/우로 분산 |
| Small (소) | 완전 소멸 (분할 없음) |

### 블록 / 벽 (Block)
- 파괴 불가능한 고정 장애물
- 방울이 블록 표면에 닿으면 정상적으로 반사됨
- 플레이어는 블록 위에 서거나 블록에 막힘

---

## 승리 조건
- 맵 내 **모든 방울이 소멸**되면 스테이지 클리어

## 패배 조건
- 플레이어가 방울에 **충돌하여 목숨이 0**이 되면 Game Over

## 목숨 시스템
- 기본 목숨 수: **3개**
- 목숨 소진 시 Game Over → 메인 화면으로 복귀

---

## 조작 요약
| 키 | 동작 |
|---|---|
| ← (Left Arrow) | 플레이어 좌측 이동 |
| → (Right Arrow) | 플레이어 우측 이동 |
| Space | 와이어 발사 |
