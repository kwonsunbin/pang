# 미션 1 (Mission 1)

## 개요
PANG의 첫 번째 스테이지로, 게임의 기본 조작과 방울 분할 메커니즘을 익히는 **튜토리얼 성격의 입문 미션**입니다.

---

## 난이도
**Easy (쉬움)**

---

## 맵 구성
- 장애물(블록) 없음 — 사방이 벽으로 둘러싸인 단순한 직사각형 맵
- 배경: 기본 단색 또는 간단한 패턴

```
┌─────────────────────────────┐
│                             │
│    ◉ (Large Bubble x2)      │
│                             │
│                             │
│                             │
│           [Player]          │
└─────────────────────────────┘
```

---

## 방울 구성
| 항목 | 값 |
|---|---|
| 초기 방울 수 | Large 2개 |
| 최종 소멸 대상 | Small 8개 (Large 1개 → Medium 2개 → Small 4개 × 2세트) |
| 초기 이동 방향 | 각각 좌/우로 분산 출발 |
| 이동 속도 | 느림 (기본 속도의 70%) |

---

## 제한 조건
| 항목 | 값 |
|---|---|
| 목숨 | 3개 |
| 제한 시간 | 없음 |
| 와이어 동시 발사 | 1개 |

---

## 클리어 조건
- 맵 내 모든 Small 방울(총 8개) 소멸

## 실패 조건
- 방울과 3회 충돌 → Game Over

---

## 학습 목표
이 미션을 통해 플레이어는 다음을 익힙니다:
1. 플레이어 이동 감각 (← → 방향키)
2. 와이어 발사 타이밍 (Space)
3. 방울 분할 메커니즘 이해 (Large → Medium → Small → 소멸)
