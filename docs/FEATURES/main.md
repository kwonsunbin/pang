# 메인 화면 구성 (Main Screen)

## 개요
게임 시작 전 플레이어가 처음 마주하는 화면입니다. 게임 타이틀, 시작 버튼, 기본 조작 안내로 구성됩니다.

## 화면 구성 요소

### 1. 타이틀 영역
- 게임 이름 **"PANG"** 을 화면 상단 중앙에 표시
- 서브타이틀 또는 슬로건 표시 (예: "모든 방울을 터뜨려라!")

### 2. 메뉴 버튼
| 버튼 | 기능 |
|---|---|
| 게임 시작 (Start) | 미션 선택 화면 또는 미션 1로 바로 진입 |
| 조작 방법 (How to Play) | 키 조작 안내 오버레이 표시 |

### 3. 조작 안내 (How to Play 오버레이)
- **방향키 ← →** : 플레이어 좌우 이동
- **Space** : 와이어 발사
- ESC 또는 닫기 버튼으로 오버레이 종료

## 전환 조건
- "게임 시작" 클릭 → Mission 1 화면으로 전환
- "조작 방법" 클릭 → 조작 안내 오버레이 표시
