# PANG 개발 계획 (PLAN.md)

> 각 Phase가 완료되면 **실제로 실행 가능한 소프트웨어**가 산출됩니다.  
> 고객님께서 직접 브라우저에서 플레이해 보시고, 각 Phase의 검수 포인트를 중심으로 피드백을 주시면 다음 단계로 진행합니다.

---

## Phase 1 — 메인 화면 & 화면 전환

### 목표
게임을 시작하기 전 처음 마주하는 **메인 화면**을 완성합니다.  
버튼을 누르면 화면이 전환되는 기본 내비게이션 구조도 함께 구축합니다.

### 구현 항목
- `PANG` 타이틀 및 슬로건 표시
- **[게임 시작]** 버튼 → 게임 화면으로 전환
- **[조작 방법]** 버튼 → 조작 안내 오버레이 표시 (← → 이동, Space 발사)
- 오버레이 닫기 버튼

### 고객님 검수 포인트
| 확인 항목 | 기대 동작 |
|---|---|
| 타이틀 노출 | "PANG" 제목과 슬로건이 화면 상단 중앙에 보인다 |
| 게임 시작 버튼 | 클릭 시 게임 화면(빈 필드)으로 전환된다 |
| 조작 방법 버튼 | 클릭 시 키 안내 오버레이가 뜬다 |
| 오버레이 닫기 | ESC 또는 닫기 버튼으로 오버레이가 사라진다 |

> **주목해 주세요:** 디자인 완성도보다 **버튼 동작과 화면 전환**이 자연스러운지를 봐주세요.

---

## Phase 2 — 게임 필드 & 플레이어 이동

### 목표
게임이 펼쳐지는 **맵(필드)** 과 키보드로 움직이는 **플레이어**를 구현합니다.  
이 단계까지 완료되면 "빈 맵 위에서 캐릭터를 좌우로 움직일 수 있는" 상태가 됩니다.

### 구현 항목
- 사방이 벽으로 둘러싸인 직사각형 게임 필드 렌더링
- 플레이어 스프라이트를 화면 하단 중앙에 배치
- ← → 방향키로 플레이어 좌우 이동
- 좌우 벽 밖으로 이동 불가 처리

### 고객님 검수 포인트
| 확인 항목 | 기대 동작 |
|---|---|
| 플레이어 위치 | 게임 시작 시 화면 하단 중앙에 캐릭터가 있다 |
| 좌우 이동 | ← → 방향키를 누르는 동안 부드럽게 이동한다 |
| 벽 충돌 | 좌우 벽 끝에서 더 이상 이동되지 않는다 |
| 키 반응 속도 | 키를 누를 때 즉각적으로 반응한다 (지연 없음) |

> **주목해 주세요:** 이동 속도가 너무 빠르거나 느리지 않은지, **조작감**을 집중적으로 느껴봐 주세요.

---

## Phase 3 — 와이어 발사

### 목표
Space 키를 누르면 플레이어 위치에서 **와이어(Wire)가 천장을 향해 발사**되는 기능을 구현합니다.

### 구현 항목
- Space 키 입력 시 플레이어 정중앙 위로 와이어 발사
- 와이어가 천장 또는 벽에 닿으면 사라짐
- **동시에 1개만 존재** — 이전 와이어가 사라져야 재발사 가능

### 고객님 검수 포인트
| 확인 항목 | 기대 동작 |
|---|---|
| 와이어 발사 | Space를 누르면 플레이어 위쪽으로 선(와이어)이 발사된다 |
| 천장 도달 | 와이어가 천장에 닿으면 사라진다 |
| 1개 제한 | 와이어가 날아가는 도중 Space를 눌러도 새 와이어가 나오지 않는다 |
| 소멸 후 재발사 | 와이어가 사라진 뒤 Space를 누르면 다시 발사된다 |

> **주목해 주세요:** 와이어가 사라지는 타이밍과 **재발사 가능 시점**이 직관적으로 느껴지는지 확인해 주세요.

---

## Phase 4 — 방울 물리 & 분할

### 목표
게임의 핵심 오브젝트인 **방울(Bubble)** 이 물리 법칙에 따라 움직이고, 와이어에 맞으면 **분할 또는 소멸**되는 로직을 구현합니다.

### 구현 항목
- Large 방울 2개가 화면 상단에서 좌/우로 이동 시작
- 중력 적용 — 바닥에 닿으면 튀어 오르고, 벽에 닿으면 반사
- 모든 방울이 동일한 최고 높이까지 튀어 오름
- 와이어 적중 시 분할 규칙 적용
  - Large → Medium 2개 (좌/우 분산)
  - Medium → Small 2개 (좌/우 분산)
  - Small → 완전 소멸

### 고객님 검수 포인트
| 확인 항목 | 기대 동작 |
|---|---|
| 방울 이동 | 방울이 좌우로 이동하며 벽에 튕긴다 |
| 바닥 반사 | 방울이 바닥에 닿으면 위로 튀어 오른다 |
| 튀는 높이 | 크기가 달라도 모든 방울이 비슷한 높이까지 올라간다 |
| Large 분할 | 와이어가 Large 방울에 맞으면 Medium 방울 2개가 좌우로 퍼진다 |
| Medium 분할 | 와이어가 Medium 방울에 맞으면 Small 방울 2개가 좌우로 퍼진다 |
| Small 소멸 | 와이어가 Small 방울에 맞으면 방울이 완전히 없어진다 |

> **주목해 주세요:** 분할 후 방울들이 **자연스럽게 퍼지는지**, 분리 방향이 어색하지 않은지 집중해서 봐주세요.

---

## Phase 5 — 충돌 판정 & 승패 시스템

### 목표
플레이어가 방울에 맞으면 목숨이 줄고, **Game Over** 또는 **Victory** 화면으로 마무리되는 완전한 게임 루프를 완성합니다.

### 구현 항목
- 플레이어-방울 충돌 감지 → 목숨 1 감소
- HUD에 남은 목숨(❤️ × 3) 표시
- 목숨 0 → **Game Over 화면** → 메인으로 복귀
- 모든 방울 소멸 → **Mission Clear 화면**
- 충돌 직후 짧은 무적 시간(깜빡임 효과) 적용

### 고객님 검수 포인트
| 확인 항목 | 기대 동작 |
|---|---|
| 목숨 표시 | 화면 어딘가에 남은 목숨이 표시된다 |
| 방울 충돌 | 플레이어가 방울에 닿으면 목숨이 줄어든다 |
| Game Over | 목숨이 0이 되면 Game Over 화면이 뜨고, 메인으로 돌아갈 수 있다 |
| Mission Clear | 모든 방울을 제거하면 클리어 화면이 뜬다 |
| 무적 시간 | 충돌 직후 잠시 동안 연속으로 피해를 입지 않는다 |

> **주목해 주세요:** 충돌 판정이 **너무 가혹하거나 느슨하지 않은지** 체감해 주세요. 억울하게 죽는 느낌이 없어야 합니다.

---

## Phase 6 — Mission 1 완성 & 전체 다듬기

### 목표
미션 1 설정을 정확히 적용하고, UI/UX를 다듬어 **완성된 1개 스테이지**를 플레이할 수 있는 상태로 마무리합니다.

### 구현 항목
- Mission 1 정식 설정 적용 (Large 2개, 이동 속도 70%, 장애물 없음)
- 게임 시작 카운트다운 또는 "Ready?" 연출
- 승리/패배 시 점수 또는 플레이 결과 간략히 표시
- 전체 UX 흐름 재점검 (메인 → 게임 → 결과 → 메인)
- 버그 수정 및 성능 최적화

### 고객님 검수 포인트
| 확인 항목 | 기대 동작 |
|---|---|
| 전체 플로우 | 메인 화면 → 게임 시작 → 플레이 → 결과 → 메인 복귀가 끊김 없이 이어진다 |
| Mission 1 난이도 | 첫 미션으로서 적절히 쉽고 방울의 움직임이 예측 가능하다 |
| 재도전 | Game Over 또는 클리어 후 다시 플레이할 수 있다 |
| 전반적 완성도 | "게임"으로서 재미있고 조작이 쾌적하다 |

> **주목해 주세요:** 이 단계에서는 전체를 **처음부터 끝까지 2~3번 플레이**해 보시고, 전반적인 게임 느낌(재미, 조작감, 밸런스)에 대해 자유롭게 피드백을 주세요.

---

## Phase 요약 로드맵

```
Phase 1  메인 화면 & 화면 전환        → 버튼/내비게이션 검수
Phase 2  게임 필드 & 플레이어 이동     → 조작감 검수
Phase 3  와이어 발사                  → 발사/제한 동작 검수
Phase 4  방울 물리 & 분할             → 물리/분할 로직 검수
Phase 5  충돌 판정 & 승패 시스템       → 게임 루프 완결 검수
Phase 6  Mission 1 완성 & 마무리      → 전체 완성도 검수
```
